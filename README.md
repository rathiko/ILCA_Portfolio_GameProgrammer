# Portfolio

物理学科に所属しながら、Unreal Engine 5とC++で、
物理をゲーム体験や映像に落とし込む作品を制作しています。

## 作品一覧

| 作品 | 内容 | 使用技術 |
| [① GalacticMoon](Source_Game①_GalacticMoon/) | 惑星やブラックホールの重力に引っ張られながら戦う3Dシューティング | UE5, C++, Blueprint |
| [② NewMoon](Source_Game②_NewMoon/) | 浮遊物の衝突を力積で自作した、無重力ステルスのミニゲーム | UE5, C++, Blueprint |
| [③ BlackHole-Simulation](Portfolio_BlackHole-Simulation/) | 光の軌道をRK4で計算し、ブラックホールの影と降着円盤の見え方を再現 | C++ |

## 各作品の見どころ

- **① GalacticMoon**：固定タイムステップとRK4による、フレームレートに依存しない軌道計算
- **② NewMoon**：物理エンジンに頼らない剛体の衝突と摩擦、エネルギー保存による検証
- **③ BlackHole-Simulation**：弱い重力場の近似から強い重力場のレイトレーシングへの発展と、温度による円盤の色やアニメーション

各フォルダのREADMEに、詳細説明と「見てほしいコード」をまとめています。
