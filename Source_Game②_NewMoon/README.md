# NewMoon

無重力空間から、浮遊物とレーザーセンサーを避けて脱出する、ステルスのミニゲームです。
触れた浮遊物が回転しながら漂い、レーザーに当たると検知されるため、物理の挙動がそのまま緊張感になります。

- 開発環境:Unreal Engine 5 / C++ / Blueprint
- 開発期間:約3週間 / 1人で開発

## 見てほしいコード

[ZeroGMotionComponent](Source_Game②_NewMoon/NewMoon/ZeroGMotionComponent.cpp)

物理エンジンを使わず、浮遊物の運動と衝突を自作したコンポーネントです。

- **接触点への力積**:接触点の速度に回転の効果を含め、有効質量から力積を求めることで、端に当たると回り、中心に当たるとまっすぐ進む挙動を実現
- **クーロン摩擦**:接線方向の力積を、法線方向の力積の μ 倍までに制限
- **相対速度での計算**:プレイヤーや他の浮遊物との衝突も、相手の速度と質量を使って同じ関数で処理
- **重力の切り替えと静止処理**:重力の再起動をパラメータ1つで表現し、床の上での振動を防ぐ処理を実装

## 検証
- 反発係数1・摩擦0の条件で、衝突前後の運動エネルギーが一致することを確認
- 条件を固定したテストで、当てる位置による回転の向きが理論どおりになることを確認
